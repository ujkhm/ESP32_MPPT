# 微型發電機測試機 — 上位機

本資料夾在 Git 上**只放免安裝執行檔與這份說明**。複製整個資料夾到 Windows 電腦即可使用，不必安裝 Python。

## 使用

1. 雙擊 `MicroGeneratorHost.exe`
2. 依畫面配對下位機藍牙（裝置名稱約為 `MicroGenerator-ESP32`），或手動選 COM 埠
3. 選擇報表儲存位置
4. 放好待測發電機，在機台上按 **START**
5. 測試結束後可存成 PDF

設定會寫在本機 `data/config.json`（不會進 Git）。鮑率 115200。

## 連線

| 項目 | 說明 |
|------|------|
| 方式 | 藍牙 SPP（Windows 虛擬 COM） |
| 鮑率 | 115200 |
| 資料 | 每行一個 JSON：`{"t":"live",...}` 約 200 ms 一次；曲線完成後另送 `{"t":"curve",...}` |

## 常見問題

**找不到藍牙裝置：** 下位機已開機、電腦藍牙已開。掃描需要幾秒。

**配對成功但連不上：** Windows 建立虛擬 COM 有時要等幾秒；逾時可改手動選埠。

**防毒攔截 exe：** 加入白名單後再執行。
